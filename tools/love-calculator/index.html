How the Love Calculator by Name Works

This calculator follows one fixed path from each name to the final score. Every English letter is assigned a Chaldean number. The letters are added to create the compound number, then reduced to a root number from 1 to 9. Each root number has a ruling planet. The two root numbers are then matched in the same compatibility matrix every time.

The complete path is:

Name → Letter Values → Compound Number → Root Number → Planet → Compatibility Score

Because the rules and matrix are fixed, repeating the same pair gives the same result. Reversing the names also keeps the same compatibility percentage.

How the Love Percentage Is Calculated

For a name with total letter value S, the root number is calculated as:

Root = 1 + ((S − 1) mod 9)

Example: JOHN = J(1) + O(7) + H(5) + N(5) = 18. Its compound number is 18, its root number is 9, and number 9 maps to Mars.

LINA = L(3) + I(1) + N(5) + A(1) = 10. Its root number is 1, which maps to the Sun.

In the compatibility matrix, root number 9 with root number 1 scores 100. So JOHN + LINA returns 100% — Strong Compatibility.

Love Calculator FAQ

Will the same two names always get the same love percentage?

Yes. The same cleaned names always create the same compound numbers, root numbers, planets, and compatibility score.

Does John + Lina give the same result as Lina + John?

Yes. The compatibility matrix is symmetric, so reversing the names does not change the final percentage.

Can I enter a full name?

Yes. You can enter a first name, nickname, or full name. Spaces and symbols are removed before the A–Z letter values are calculated.

Why does the Chaldean table have no letters assigned directly to 9?

The letter table assigns direct letter values from 1 through 8. A root number of 9 can still appear after the full name total is reduced.

What is the compound number?

The compound number is the full sum of all letter values before reducing the total to a root number from 1 to 9.

Which planets are used?

The tool maps 1 to Sun, 2 to Moon, 3 to Jupiter, 4 to Rahu, 5 to Mercury, 6 to Venus, 7 to Ketu, 8 to Saturn, and 9 to Mars.
